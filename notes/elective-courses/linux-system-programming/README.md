# Linux 系统编程

**系统软件方向的必修课**。介绍 Linux 系统的相关知识。

## 课程总评分布

| 类别 | 占比  | 备注                             |
| -- | --- | ------------------------------ |
| 平时 | -   | 后半学期实在是没啥人来了，每节课都点名，点到的会有一定的加分 |
| 实验 | 40% |                                |
| 期末 | 60% |                                |

## 实验

两周一次。助教很仁慈，实验要求也不高，应该没啥难度。

## 期末

最后两节课会划重点，考前速通一下总没错。

不幸的是，有很多不会考的内容也被纳入了重点，导致重点奇长无比，速通时难以全部背完。

好在老师的捞人能力还是很强的，全部填满应该就能及格。
