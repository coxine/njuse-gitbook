# 软件系统设计

本课程主要分为两部分，前半部分为设计模式，系常规的软件工程知识；后半部分为软件架构设计，系南软独创的软件工程知识。

## 平时听课

设计模式部分和 C++ 体验类似，架构部分来的人稀稀拉拉。站长的笔记都是课后再整理的，所以你懂的……

## 课程作业

### 设计模式

* 小组作业：给定文档，完成一个简单的内存文件系统的开发，十分轻松
  * ~~这还能作为小组作业的~~
  * [参考版本](https://github.com/coxine/software-design-pattern-homework/)（2026春）

### 架构

* 个人作业：zh老师部分，提交一次书面文档，回答一些问题
* 小组作业：lss老师部分，基于 AI Agent 在课堂上完成一个 ADD 设计，并提交源码和文档（时间比较紧张，建议在那次上课前提前准备好）

## 期末考试

### 设计模式

* 小题以理解性问题为主，不会画重点
* 大题
* 建议把 PPT 都过一遍，记熟设计模式的英文名称、优缺点、使用场景、类图等
* 不必死抠细节，方向对即可得分
* 可利用资料库中的 `设计模式总表.xlsx` 辅助复习

### 架构

* 最后一节课会画重点，可基于往年卷和提到的重点针对性背诵
* 毫无逻辑可言，若时间有限建议抓大放小
