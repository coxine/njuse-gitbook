# 01-软件设计原则

## 面向对象设计原则

* 目标：开闭原则
* 指导：最小知识原则（迪米特法则）
* 基础：单一职责原则、可变性封装原则
* 实现：依赖倒置原则、合成复用原则、里氏代换原则、接口隔离原则

| 中文      | 英文                                            | 定义                                                                        |
| ------- | --------------------------------------------- | ------------------------------------------------------------------------- |
| 单一职责原则  | Single Responsibility Principle (SRP)         | 类的**职责要单一**，不能将太多职责放在一个类中                                                 |
| 开闭原则    | Open-Closed Principle (OCP)                   | 软件实体**对扩展开放，对修改封闭**。在不修改一个软件实体的基础上去扩展其功能                                  |
| 里氏代换原则  | Liskov Substitution Principle (LSP)           | 在软件系统中，一个可以接受基类对象的地方必然可以接受一个子类对象                                          |
| 依赖倒转原则  | Dependency Inversion Principle (DIP)          | 要针对**抽象层**编程，而不要针对具体类编程                                                   |
| 接口隔离原则  | Interface Segregation Principle (ISP)         | 客户端不应依赖其不需要的接口，使用多个专门的接口来取代一个统一的接口                                        |
| 合成复用原则  | Composite Reuse Principle (CRP)               | 尽量多地使用**组合和聚合**，尽量少使用继承                                                   |
| 迪米特法则   | Law of Demeter (LoD)                          | 一个软件实体对其他实体的引用越少越好，或者说如果两个类不必彼此直接通信，那么这两个类就不应当发生直接的相互作用，而是通过引入一个第三者发生间接交互 |
| 可变性封装原则 | Principle of Encapsulation of Variation (EVP) | 封装系统的可变因素                                                                 |

### 分析

* OCP 是对 SRP 的加强
* 需要通过抽象化实现 OCP：LSP 和 DIP 是 OCP 的具体实现
* ISP 拆分时要满足 SRP

## 设计模式概览

* 类模式：处理类和子类之间的关系，编译时静态确定
* 对象模式：处理对象之间的关系，运行时动态确定

|      | 创建型模式                                  | 结构型模式                                                            | 行为型模式                                                  |
| ---- | -------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| 目的   | 提供创建对象的机制                              | 负责对象之间的组合                                                        | 负责对象之间的沟通交互                                            |
| 类模式  | <p>简单工厂模式<br>工厂方法模式</p>                | （类）适配器模式                                                         | 模板方法模式                                                 |
| 对象模式 | <p>抽象工厂模式<br>建造者模式<br>原型模式<br>单例模式</p> | <p>（对象）适配器模式<br>桥接模式<br>组合模式<br>装饰模式<br>外观模式<br>享元模式<br>代理模式</p> | <p>命令模式<br>迭代器模式<br>中介者模式<br>观察者模式<br>状态模式<br>策略模式</p> |
